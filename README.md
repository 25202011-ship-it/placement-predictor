# HR Job Placement Predictor

Streamlit web app built on SAS Studio (regression) and SAS Viya (classification) model outputs.

- `app.py`: the web app
- `placement_data.csv`: cleaned dataset (39,005 rows)
- `requirements.txt`: Python packages for Streamlit Cloud

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`
